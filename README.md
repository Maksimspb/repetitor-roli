# 🎭 Репетитор роли

Веб-тренажёр для заучивания текста роли в спектакле. Партнёр по сцене озвучивает
чужие реплики голосом, ты говоришь свои по памяти — учишь **связки** «реплика → ответ».
Приложение **слушает микрофон**, показывает вживую что расслышало и в конце сцены
выдаёт **сводку: где попал, где нет, процент точности**.

Пьеса по умолчанию: **«Волки и овцы»** А. Н. Островского (расширенная версия с народом и песней).

## 📱 Открыть на телефоне (в т.ч. в машине)

**Живая версия: https://maksimspb.github.io/repetitor-roli/**

Поставить на iPhone как приложение: открой ссылку в **Safari** → кнопка «Поделиться» →
**«На экран „Домой“»**. Появится иконка 🎭, запускается на весь экран.

- **Режим «🚗 Без рук (для машины)»** — включи в настройках перед стартом. Партнёр играет
  сцену сам, делает паузу под твою реплику. Телефон трогать не надо, **микрофон не нужен —
  работает офлайн** (после первого открытия). Идеально для машины.
- **Проверка речи с подсветкой** на iPhone работает плохо (Safari не поддерживает распознавание) —
  её используй на Маке/в Chrome. На телефоне — партнёр и связки.

> **Зачем это.** Существующие приложения для актёров (LineLearner, coldRead, ScenePartner…)
> — англоцентричны и заточены под короткие киносайды. **Пословной проверки текста
> на русском для театральной пьесы нет ни у кого** — это и есть ниша проекта.
> Подробнее — [`docs/MARKET-RESEARCH.md`](docs/MARKET-RESEARCH.md).

## Быстрый старт

```bash
git clone <repo-url> репетитор-роли
cd репетитор-роли
pip3 install python-docx        # только для пересборки пьесы из docx
./run.sh
```

Открой **http://localhost:8777** на Маке, или с телефона в той же Wi-Fi —
адрес `http://<ip-мака>:8777` скрипт покажет сам.

> Требуется Python 3. Ничего больше для запуска не нужно — TTS и распознавание
> речи работают в браузере (Web Speech API).

## Как пользоваться

1. Выбери **свою роль** (список с числом реплик).
2. Появится список **только тех сцен, где роль есть** — с описанием (с кем сцена,
   сколько твоих реплик, первая строка). Выбери сцену или «▶ Все мои сцены подряд».
3. Выбери **режим показа твоих реплик**: скрыто / первые буквы (`Г···· С·····`) / целиком.
4. **Начать репетицию.**
   - **Партнёр** (не твоя роль) — приложение показывает и **озвучивает** реплику, идёт дальше.
   - **Твоя реплика** — текст скрыт, внизу горит 🔴 «слушаю…», вживую печатается распознанное.
     Сказал — жмёшь **Дальше** (или `пробел`). Реплика раскрашивается: зелёное — попал,
     красное — пропустил. Кнопка **Показать** — если забыл.
5. В конце — **сводка** по всем твоим репликам с процентом и разбором ошибок.

## Статус (что уже работает)

| Фаза | Что | Статус |
|------|-----|--------|
| **0. Парсер** | docx → структурный JSON (акты, явления, реплики, роли) | ✅ готово |
| **1. Партнёр** | выбор роли/сцены, TTS-озвучка партнёра, скрытие своих реплик | ✅ готово |
| **2. Проверка (браузерная)** | распознавание речи, пословный дифф, подсветка ошибок, сводка | ✅ базово (Web Speech API) |
| **2+. Проверка (Whisper)** | локальный Whisper вместо браузерного ASR — точнее на русском | ⬜ следующий шаг |
| **3. Умное** | LLM-судья перифраза, авто-передача хода, интервальные повторения, голос на персонажа | ⬜ план |

Полный дневник разработки, решения и рефлексии — [`docs/DEVLOG.md`](docs/DEVLOG.md).

## Структура репозитория

```
репетитор-роли/
├── index.html            всё приложение (Фазы 1–2): UI, TTS, ASR, дифф, сводка
```

## Продолжить разработку на другом компе

```bash
git clone <repo-url> && cd репетитор-роли
pip3 install python-docx
./run.sh
```

Сначала прочитай [`docs/DEVLOG.md`](docs/DEVLOG.md) — там текущее состояние, принятые
решения и приоритетные задачи. Технику смотри в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

канонический словарь имён в [`parse.py`](parse.py) (`CANON`), запусти `python3 parse.py`.

## Известные ограничения

- **Голос металлический**, пока не скачан улучшенный системный голос.
  macOS: Системные настройки → Универсальный доступ → Устный контент → Голос системы →
  Управление голосами → Русский → **Milena (Enhanced/Premium)**. Siri-голоса браузеру недоступны.
- **Браузерное распознавание** (Web Speech API) в Safari капризно и шлёт звук в облако Apple.
  В Chrome стабильнее. Радикальное решение — локальный Whisper (Фаза 2+).
- Распознавание требует **интернет** (браузерный ASR облачный). Локальный Whisper снимет это.
