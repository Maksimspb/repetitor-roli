# Голос партнёра: как сделали живым и бесплатным

Итог глубокой сессии по бесплатному улучшению русского голоса.

## Решение (внедрено)

**Архитектура пред-рендера + edge-tts.** Все реплики пьесы один раз озвучиваются на Маке
лучшим бесплатным нейроголосом и кладутся в репозиторий как mp3. Приложение играет готовые
файлы вместо системного голоса; Service Worker кеширует их → **живой голос работает офлайн
в машине**. Системный голос (Web Speech) остаётся аварийным фолбэком.

- **Движок:** [`edge-tts`](https://github.com/rany2/edge-tts) — Microsoft Neural TTS,
  бесплатно, без API-ключа. Самый «живой» русский из бесплатного.
- **Голоса:** `ru-RU-SvetlanaNeural` (жен.) + `ru-RU-DmitryNeural` (муж.). Из двух голосов
  сделана «труппа»: каждому персонажу — свой тембр через сдвиги высоты/темпа (см. `VOICE_MAP`
  в [`build_audio.py`](../build_audio.py)).
- **Почему пред-рендер, а не live-бэкенд:** бэкенд работает только у Мака; в машине с iPhone
  без интернета — никак. Пред-рендер играет из кеша, офлайн, мгновенно, и позволяет
  использовать хоть самый медленный движок (рендер разовый).

## Как это устроено в коде

```
build_audio.py  → audio/<id реплики>.mp3  + audio/index.json (id → файл)
index.html      → voicePartner(u): играет audio/<id>.mp3, при сбое → системный голос
sw.js           → кеширует mp3 при первом проигрывании (network-first)
```
Каждая реплика имеет стабильный `id` (проставляет `parse.py`). iOS требует разблокировки
звука жестом — используется один `<audio>`-элемент, «прогретый» тишиной по клику «Начать».

## Перегенерировать озвучку

```bash
python3 -m venv .venv-tts && .venv-tts/bin/pip install edge-tts
.venv-tts/bin/python build_audio.py                 # все реплики (готовые пропускает)
.venv-tts/bin/python build_audio.py --role Лыняев   # только реплики партнёров Лыняева
.venv-tts/bin/python build_audio.py --force         # перезаписать всё
```
Поменял голоса в `VOICE_MAP` или текст пьесы → перегенерируй затронутые (или `--force`),
`git add audio && git commit && git push` → GitHub Pages обновит, iPhone подхватит.

## Разобранные альтернативы (бесплатные)

| Движок | Живость | Офлайн | Лицензия | RU-голоса | Вывод |
|---|---|---|---|---|---|
| **edge-tts (MS Neural)** | Очень высокая | Нет (облако) | Серая зона ToS, пакет свободный | Svetlana, Dmitry, Dariya | **Взято** — для пред-рендера онлайн-зависимость не мешает |
| **Silero v4/v5** | Высокая | **Да** | CC-BY-NC (v4), MIT (v5) | 5: aidar, baya, kseniya, xenia, eugene | Резерв для до-генерации офлайн на Маке (нужен torch) |
| **Piper** | Средняя (ударения!) | Да | MIT | ruslan, irina, denis, dmitri | Лёгкий, но мажет ударения в русском |
| **Coqui XTTS-v2** | Очень высокая + клон | Да | CPML (только некоммерч.) | клон по 6-сек сэмплу | **Идея на будущее:** клонировать голос реального партнёра |
| **Kokoro** | Высокая | Да | Apache-2.0 | нет русского | Не подходит |
| **macOS Milena/Siri** | Enhanced — средняя | Да | системная | Milena | Web Speech аудио не сохраняет → только фолбэк |
| **Google Cloud TTS** | Очень высокая | Нет | free-tier 1М симв/мес | WaveNet/Neural2 ru | Требует биллинг-аккаунт |
| **Yandex SpeechKit** | Очень высокая (лучший RU) | Нет | только триал-кредиты | alena, filipp… | Не бесплатен постоянно |

## Идея на будущее: голос реального партнёра

XTTS-v2 клонирует тембр по записи ~10–30 сек. Можно озвучить реплики конкретного партнёра
по сцене его же голосом (лицензия только для личного использования). Тяжело на CPU — только
пред-рендером. Самый «магический» апгрейд, если захочется.
